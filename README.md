<h1>MultiLearn – Tutor Finder Platform (Frontend)</h1>

MultiLearn is a responsive website created to present a mobile and web application designed to help students and pupils find suitable tutors.  
The website serves as a promotional and presentation platform, focusing on user experience, clean design, and smooth animations.

<h2>Design</h2>

Custom-made UI design created by me.  
https://bit.ly/multi-learn

<h2>Technologies Used</h2>

- HTML5  
- CSS3  
- JavaScript  
- Bootstrap  

<h2>Project Purpose</h2>

This project was built to:

- Present the MultiLearn tutor-finding application  
- Practice responsive web design and modern UI principles  
- Improve front-end development skills using HTML, CSS, JavaScript, and Bootstrap  
- Implement animations and interactive elements  

<h2>Features</h2>

- Fully responsive design (desktop, tablet, and mobile)  
- Custom-made UI design  
- Smooth animations and transitions  
- Multiple pages:
  - Home  
  - About Us  
  - Contact  
  - Login  
  - Register  
- Clean and user-friendly layout  

<h2>How to Run the Project</h2>

This project can be run using a local development server.

<strong>Recommended method: Live Server</strong>

- Open the project folder in Visual Studio Code  
- Install the Live Server extension  
- Right-click on <code>index.html</code>  
- Select <strong>“Open with Live Server”</strong>  

The website will open in your browser and display correctly.
